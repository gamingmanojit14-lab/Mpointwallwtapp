📘 Merchant API Docs

Overview

P2P Wallet backend — এ হোস্ট করা। TextilePOS (বা যেকোনো POS) এই API ব্যবহার করে customer-এর P2P wallet থেকে points debit/credit করতে পারে।

🔐 Authentication

প্রতিটি request-এ ২টি header দিতে হবে:

x-api-key: sk_live_xxxxxxxxxxxxxxxxxxxxxxxx
x-shop-id: SHOP-A3K9Q7

Secret code কখনো client-side JS-এ বসাবেন না — শুধু server-side থেকে call করুন।

POST /api/verifyConnection

Integration valid কিনা এবং merchant wallet info check করে।

Example:

curl -X POST https://your-api/api/verifyConnection \
  -H "x-api-key: sk_live_..." \
  -H "x-shop-id: SHOP-A3K9Q7"

Response:

{
  "success": true,
  "shopName": "Sri Krishna Fastfood",
  "shopId": "SHOP-A3K9Q7",
  "merchantWalletId": "M-B7X4M2",
  "status": "active",
  "allowAutoDebit": true,
  "allowAutoCredit": true
}
POST /api/debitPoints

Customer wallet থেকে merchant wallet-এ points transfer (customer pays)।

Body:

{
  "customerWalletId": "W-A3K9Q7M2",
  "amount": 500,
  "externalRef": "INV-2024-001",
  "note": "POS sale"
}

Response:

{
  "success": true,
  "txId": "TX-1710000000-abc123",
  "newBalance": 350
}
POST /api/creditPoints

Merchant wallet থেকে customer wallet-এ points দেয় (loyalty earn / cashback)।

Body:

{
  "customerWalletId": "W-A3K9Q7M2",
  "amount": 5,
  "externalRef": "INV-2024-001",
  "note": "Loyalty earn 1%"
}

Response:

{
  "success": true,
  "txId": "TX-1710000001-def456",
  "newBalance": 355
}
GET /api/getBalance?walletId=W-XXXXXX

Wallet এর current balance + status।

Response:

{
  "success": true,
  "walletId": "W-A3K9Q7M2",
  "balance": 355,
  "walletStatus": "active",
  "name": "Rahim Uddin",
  "isMerchant": false
}
POST /api/createPaymentRequest

Customer-কে QR scan করে pay করার জন্য payment request তৈরি করে।

Body:

{
  "amount": 500,
  "invoiceNo": "INV-2024-001",
  "expiresIn": 300
}

Response:

{
  "success": true,
  "requestId": "PR-1710000000-a1b2c3d4",
  "paymentURL": "https://wallet.web.app/pay.html?r=PR-...",
  "expiresAt": 1710000300000,
  "signature": "abc..."
}

`paymentURL` QR code-এ encode করে customer-কে দেখান।

GET /api/paymentStatus?requestId=PR-XXX

Payment request-এর current status check।

Response:

{
  "success": true,
  "requestId": "PR-...",
  "status": "paid",
  "amount": 500,
  "paidByWalletId": "W-A3K9Q7M2",
  "txId": "TX-...",
  "expiresAt": 1710000300000
}

⚠️ Error Responses

StatusMeaning
400Invalid params / insufficient balance
401Missing or invalid secret code
403Integration paused / action not allowed
404Wallet or request not found
410Payment request expired
429Rate limit exceeded (100/min)
500Server error
